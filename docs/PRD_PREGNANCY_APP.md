# 孕期 App PRD

## 1. 文档信息

- 产品名称：云期 App
- 产品定位：面向孕期妈妈的孕周管理、提醒规划与孕期记录工具
- 文档版本：v0.1
- 创建日期：2026-06-21
- 当前阶段：需求定义
- 目标平台：Android

## 2. 产品概述

云期 App 是一款为孕期妈妈设计的个人孕期管理工具。用户可以输入末次月经日期、预产期、受孕日期或当前孕周，App 自动推算当前孕周、孕天、预产期和阶段信息，并基于当前孕周展示每日提醒、饮食建议、运动建议、产检安排和记录入口。

产品的核心价值不是替代医生诊断，而是帮助用户把孕期大量零散事项变成可查看、可提醒、可记录、可追踪的日常流程。

## 3. 背景与问题

孕期用户通常面临以下问题：

- 孕周计算容易混乱，不清楚当前处于哪个阶段。
- 每个孕周的注意事项、产检安排、饮食禁忌、运动边界分散在不同渠道。
- 体重、胎动、产检时间、症状等记录缺少统一入口。
- 日常提醒依赖备忘录或聊天记录，容易遗漏。
- 医疗信息存在风险，用户需要清晰知道哪些信息仅供参考、哪些情况应及时联系医生。

## 4. 产品目标

### 4.1 用户目标

- 快速知道“今天孕几周几天”和“距离预产期还有多久”。
- 每天打开 App 就能看到适合当前孕周的提醒、饮食建议和运动建议。
- 在日历中记录产检、体重、胎动、症状和备注。
- 通过趋势图回看体重变化、胎动记录和产检计划。
- 在异常记录或高风险提示场景下获得清晰的就医提醒。

### 4.2 业务目标

- 完成一个可持续扩展的孕期管理基础产品。
- MVP 先覆盖孕周推算、每日建议、提醒、日历记录四个核心闭环。
- 后续可扩展为家庭共享、医生协作、内容订阅、产后管理、宝宝成长记录等模块。

### 4.3 成功指标

- 新用户完成孕期信息设置率 >= 85%。
- 次日留存率 >= 35%，7 日留存率 >= 18%。
- 每周至少记录一次的活跃用户占比 >= 40%。
- 日历记录创建成功率 >= 98%。
- 本地提醒触达成功率 >= 95%。
- 核心崩溃率 < 0.3%。

## 5. 非目标

MVP 阶段不做：

- 医疗诊断、风险分级诊断、处方建议。
- 医生在线问诊。
- 医疗器械数据接入。
- 社区、直播、电商。
- iOS 版本。
- 云同步与多端登录。
- 复杂 AI 问答或自动医疗解释。

## 6. 医疗与安全边界

App 所有孕期建议必须遵守以下原则：

- 明确展示“内容仅供记录和健康管理参考，不能替代医生建议”。
- 遇到胎动明显减少、无胎动、出血、剧烈腹痛、严重头痛、视物模糊、持续发热、破水、宫缩异常等情况，提示用户立即联系医生或当地急救服务。
- 饮食和运动建议必须可追溯来源，并保留更新时间。
- 不根据用户输入给出诊断结论。
- 不使用恐吓式文案。
- 不默认用户适合所有运动；必须提示有合并症、高危妊娠或医生限制时遵医嘱。
- 胎动记录以“了解自己的日常模式”为主，不用单一固定次数阈值替代医疗判断。

## 7. 目标用户

### 7.1 核心用户

- 已怀孕 4-40 周的孕期妈妈。
- 第一次怀孕、需要更多流程指导的用户。
- 希望系统记录产检、体重和胎动的用户。

### 7.2 次要用户

- 备孕后刚确认怀孕的用户。
- 孕妇伴侣或家人。
- 产后希望继续保留孕期记录的用户。

## 8. 用户画像

### 用户 A：第一次怀孕的新手妈妈

- 需求：知道每周要注意什么，别错过产检。
- 痛点：信息太多，不知道哪些适合自己当前孕周。
- 关键功能：孕周首页、每日提醒、产检日历。

### 用户 B：重视数据记录的孕妈妈

- 需求：记录体重、胎动和症状，产检时方便回看。
- 痛点：记录分散，趋势不直观。
- 关键功能：日历记录、趋势图、导出。

### 用户 C：工作繁忙的孕妈妈

- 需求：提前提醒产检、补充叶酸/复合维生素、运动和喝水。
- 痛点：容易忘记。
- 关键功能：本地提醒、日程同步、快捷记录。

## 9. 核心用户流程

### 9.1 首次使用流程

1. 用户打开 App。
2. 查看隐私与医疗免责声明。
3. 选择孕期计算方式：
   - 末次月经日期
   - 预产期
   - 受孕日期
   - 当前孕周加孕天
4. 可选填写：
   - 身高
   - 孕前体重
   - 单胎/双胎
   - 是否医生限制运动
5. App 生成当前孕周、孕天、预产期和今日任务。
6. 用户进入首页。

### 9.2 每日使用流程

1. 用户进入首页。
2. 查看今天孕周、胎儿/妈妈阶段提示、今日提醒。
3. 查看饮食建议与运动建议。
4. 快捷记录体重、胎动、症状或备注。
5. App 将记录同步到日历。

### 9.3 日历记录流程

1. 用户进入日历。
2. 选择日期。
3. 添加记录类型：
   - 产检
   - 体重
   - 胎动
   - 症状
   - 运动
   - 饮食
   - 备注
4. 保存后在日历上展示标记。
5. 支持按类型筛选。

### 9.4 产检提醒流程

1. 用户新增产检事项。
2. 设置日期、时间、医院、医生、检查项目、备注。
3. 设置提前提醒。
4. 到时间触发系统通知。
5. 产检完成后可补充结果和附件备注。

## 10. 功能范围

### 10.1 P0 MVP 功能

#### 10.1.1 孕期设置与推算

功能描述：

- 用户可通过末次月经日期、预产期、受孕日期或当前孕周设置孕期信息。
- App 自动推算当前孕周、孕天、预产期和妊娠阶段。
- 支持用户后续修改。

规则：

- 默认以末次月经日期为基准。
- 预产期默认按末次月经日期加 280 天计算。
- 若用户输入当前孕周，则反推估算末次月经日期。
- 所有日期计算按本地时区自然日处理。
- 超过 42 周时提示“可能已过预产期，请以医生判断为准”，不自动切换产后。

验收标准：

- 输入末次月经日期后能正确显示孕周和预产期。
- 输入预产期后能反推当前孕周。
- 输入当前孕周后能生成估算预产期。
- 修改孕期设置后首页和日历同步更新。

#### 10.1.2 首页孕周看板

展示内容：

- 当前孕周：例如 18 周 3 天。
- 所属孕期阶段：孕早期、孕中期、孕晚期。
- 距离预产期天数。
- 今日提醒列表。
- 今日饮食建议。
- 今日运动建议。
- 快捷记录按钮：体重、胎动、产检、症状。

验收标准：

- 首页打开时间 < 1.5 秒。
- 没有网络时仍可展示本地内容。
- 今日建议随孕周变化。

#### 10.1.3 每日提醒

提醒类型：

- 产检提醒。
- 体重记录提醒。
- 胎动记录提醒。
- 补充叶酸/维生素提醒。
- 饮水提醒。
- 运动提醒。
- 自定义提醒。

规则：

- 用户可开启/关闭每类提醒。
- 支持提醒时间设置。
- 系统通知使用 Android 本地通知。
- 不强制推送医疗结论。

验收标准：

- 用户设置提醒后，能在指定时间收到通知。
- 修改提醒时间后立即生效。
- 关闭提醒后不再触发。

#### 10.1.4 饮食规划与建议

MVP 以“建议卡片 + 每日重点 + 禁忌提醒”为主，不做复杂食谱生成。

内容包括：

- 每日饮食重点。
- 当前孕周常见营养关注点。
- 鱼类摄入和低汞选择提示。
- 叶酸提示。
- 食品安全提醒。
- 用户可收藏或标记已读。

验收标准：

- 每个孕周至少有 1 条饮食建议。
- 所有建议有来源字段和更新时间。
- 文案中避免“保证、治愈、诊断”等医疗承诺。

#### 10.1.5 运动建议

内容包括：

- 当前孕周适合的低强度或中等强度运动建议。
- 每周目标提示。
- 注意事项和禁忌提醒。
- 用户可记录运动类型、时长和备注。

安全规则：

- 若用户设置“医生限制运动”，首页不展示默认运动建议，只展示遵医嘱提示。
- 孕中晚期避免展示仰卧类动作作为推荐动作。
- 提醒用户运动前确认自身状态。

验收标准：

- 每个孕期阶段至少有一组运动建议。
- 运动建议可被关闭。
- 记录运动后进入日历。

#### 10.1.6 日历功能

视图：

- 月视图。
- 日详情列表。
- 类型筛选。

记录类型：

- 产检：日期、时间、医院、医生、项目、结果、备注。
- 体重：日期、体重、备注。
- 胎动：日期、时间段、次数或感受、备注。
- 症状：类型、强度、备注。
- 运动：类型、时长、强度、备注。
- 饮食：餐次、内容、备注。
- 通用备注。

验收标准：

- 日历中有记录的日期显示标记。
- 点击日期可查看全部记录。
- 支持新增、编辑、删除记录。
- 删除前二次确认。

#### 10.1.7 数据趋势

MVP 趋势包括：

- 体重趋势。
- 胎动记录趋势。
- 运动时长趋势。

验收标准：

- 有 2 条及以上记录时展示折线或柱状趋势。
- 无数据时展示空状态和记录入口。

### 10.2 P1 功能

- 产检模板：按孕周推荐常见产检项目。
- 记录导出：PDF 或 CSV。
- 家人共享只读视图。
- 附件照片：产检单拍照保存。
- 云备份。
- 多语言和地区化内容。
- 桌面小组件。

### 10.3 P2 功能

- 产后恢复记录。
- 宝宝出生后成长记录。
- AI 内容问答，但必须强医疗边界和来源展示。
- 医生协作或机构合作。

## 14. 权限需求

MVP 需要：

- 通知权限：用于本地提醒。

可能后续需要：

- 相机权限：拍摄产检单。
- 文件权限或系统分享能力：导出记录。
- 日历权限：同步到系统日历。

## 15. 隐私与数据安全

- MVP 默认本地存储，不上传云端。
- 用户可一键删除全部本地数据。
- 敏感信息不写入日志。
- Crash 日志不得包含孕期记录、备注、医院、医生等个人信息。
- 后续如做云同步，必须增加账号体系、隐私政策、数据加密和删除机制。

## 16. 关键页面说明

### 16.1 首页

- 顶部显示孕周和预产期倒计时。
- 中部显示今日提醒。
- 下方显示饮食、运动、产检建议。
- 底部提供快捷记录。

### 16.2 孕期设置页

- 支持多种计算方式。
- 展示推算结果预览。
- 支持修改并提示会影响历史建议展示。

### 16.3 日历页

- 月历占上半屏。
- 下半屏显示所选日期记录。
- 右下角提供新增入口。

### 16.4 新增记录页

- 先选记录类型，再展示对应表单。
- 保存后回到日期详情。

### 16.5 趋势页

- 卡片式展示体重趋势、胎动趋势、运动趋势。
- 支持按 7 天、30 天、全部筛选。

## 17. 异常与边界场景

- 用户输入预产期早于今天且超过 42 周：提示确认日期。
- 用户输入孕周超过 42 周：提示可能输入有误。
- 用户删除孕期档案：二次确认，并说明将影响首页和提醒。
- 用户关闭通知权限：提醒设置页展示引导。
- 用户记录胎动明显异常感受：展示“请及时联系医生或产科单位”的提醒，不做判断。

## 18. 验收标准

MVP 发布前必须满足：

- 用户可完成孕期设置。
- 首页能显示正确孕周和今日建议。
- 用户可新增、编辑、删除日历记录。
- 用户可创建产检提醒并收到本地通知。
- 体重和胎动记录可在趋势页展示。
- 离线可用。
- 医疗免责声明和紧急提醒可见。
- Android 真机基本流程通过。
